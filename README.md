# OurWorld — Android App 🏡♥

A cozy, romantic Android application for long-distance couples to share and decorate a virtual home, grow a garden, exchange hidden handwritten notes, and build memories together.

## Highlights

- **Native Kotlin Android Shell (`MainActivity.kt`)**: Full-screen portrait experience with warm pastel system bars, local state persistence, native haptic feedback on couple moments, and Android's native Share Sheet for sending your couple pairing code.
- **Complete Cozy Experience**: Customizable chibi avatars, pairing code, interactive 2D home with draggable furniture/wallpapers/lighting/weather, shared garden, daily couple challenges & rewards, Cozy Shop, hidden surprises, and Polaroid Memories.

## Build the APK in Two Ways

### Option 1: Automatic Cloud APK Build via GitHub Actions (No Local Setup)
1. Push this project to a GitHub repository on the `main` branch.
2. Open the **Actions** tab on GitHub and click the latest **Build OurWorld Android APK** run.
3. Download the **OurWorld-Android-APK** artifact (`app-debug.apk`) and install it on your Android phone.

### Option 2: Open in Android Studio
1. Unzip and open this folder in **Android Studio** (Ladybug or newer, JDK 17).
2. Let Gradle sync, then click **Run** to deploy to your Android phone/emulator, or choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
